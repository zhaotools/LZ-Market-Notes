# 设计说明

## 定位

这是老赵的个人内容入口，而不是第二个工具箱销售官网。读者先认识作者，再看到市场观察与内容，最后按需要进入专业工具。

## 首页阅读顺序

个人介绍与四季概念示意 → 公开市场阶段概览 → 公众号笔记 → 视频与案例 → 四层工具 → 关于与关注入口。

主标题：“看清市场的四季，记录投资的思考。”

副标题：“你好，我是老赵。一名技术型投资研究者。在这里，分享市场观察、系统工具，以及 AI 带来的新可能。”

个人署名使用文字标记“赵”，是本版界面标记，不宣称复用了某份正式 Logo 原文件。

## 视觉

页面背景白与浅灰蓝，正文深蓝，操作主色 #205BDF。卡片圆角 10–18px，以留白和细边框区分，不使用大面积霓虹渐变或拥挤终端样式。

四季语义：S1 春蓝 #3375D8；S2 夏绿 #278667；S3 秋橙 #AF7426；S4 冬暗红 #9B4E61。颜色只表示所处阶段，不代表资产优劣、交易动作或保证未来方向。

中文使用系统字体栈。未打包或分发字体文件，无外部字体请求。

首页右侧曲线为概念图，已标注“非历史行情”；视频与文章的文字封面为版式设计，不冒充原平台封面。

## 交互与移动端

桌面端市场为 4 列卡片，手机端为 2 列；视频手机端单列；工具卡片手机端两列。文章页有分类、关键词搜索、排序与无结果提示。市场看板支持阶段与市场组合筛选。

导航使用正常多页面链接，部署不需要 SPA 路由回退。独立 preview.html 额外嵌入六个模板，使用 hash 路由实现离线验收。

真实视频点击后才创建 iframe，关闭弹窗销毁 iframe。待接入主题显示明确提示并保留频道入口。

包含键盘焦点样式、跳至正文链接、语义标题、弹窗 Escape 关闭、按钮可访问名称、低动态效果偏好与搜索结果播报。尚未进行完整的屏幕阅读器或 WCAG 审计，不能把这些实现项当成合规认证。

## 页面边界

不放价格、收益承诺、实时买卖提醒或虚构的访问量。不生成假的二维码、日期或视频时长。未确认的内容以样例呈现，真实数据保留快照日期。
